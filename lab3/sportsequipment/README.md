# Лабораторна робота №3. Реалізація обробки винятків

## Предметна область
Система управління магазином квітів (Rosemary Shop).

## Опис реалізації
В рамках лабораторної роботи реалізовано:
1. **Рівень 1 (Базовий):** Використано конструкцію `try-catch-finally` для перехоплення стандартних винятків `InputMismatchException` (некоректний ввід з клавіатури) та `ArrayIndexOutOfBoundsException` (звернення до неіснуючого товару). В блоці `finally` гарантовано закривається `Scanner`.
2. **Рівень 2 (Середній):** Створено власні checked винятки `InvalidPriceException` та `InsufficientStockException`, які містять додаткові поля (наприклад, інформацію про запитану та наявну кількість товару).
3. **Рівень 3 (Високий):** 
   - Побудовано ієрархію винятків (базовий клас `FlowerShopException`).
   - Реалізовано множинну обробку `catch` з дотриманням порядку від специфічних до загальних.
   - Продемонстровано механізм `re-throw` у методі `processPurchase()`, де помилка логується і прокидається на рівень `main`.

## Інструкція для запуску
1. Скомпілюйте файли: `javac Main.java`
2. Запустіть програму: `java Main`
3. Для перевірки `InputMismatchException` — введіть літеру замість цифри.
4. Для перевірки `ArrayIndexOutOfBoundsException` — введіть номер квітки `5`.
5. Для перевірки `InsufficientStockException` — введіть коректний номер квітки, але кількість `100`.
