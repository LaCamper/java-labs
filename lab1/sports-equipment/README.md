# Лабораторна робота №1

## Тема

Реалізація консольного застосунку мовою Java.

## Предметна область

Облік спортивного інвентарю.

## Опис сутності

У програмі використовується сутність "Спортивний інвентар".

Основні характеристики:

* назва інвентарю;
* категорія;
* кількість одиниць;
* ціна за одну одиницю;
* відсоток зносу.

Програма розраховує:

* загальну вартість інвентарю;
* поточну вартість з урахуванням зносу;
* стан інвентарю залежно від відсотка зносу.

## Запуск програми

Для компіляції програми:

```bash
javac -encoding UTF-8 Main.java
```

Для запуску:

```bash
java Main
```

## Використані можливості Java

* локальні змінні;
* типи `String`, `int`, `double`;
* введення даних через `Scanner`;
* оператори `if`, `else if`, `else`;
* арифметичні операції;
* форматований вивід через `printf`.
